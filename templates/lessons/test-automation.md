# Lessons: test-automation

Rules learned from automation-verifier denials of automated tests. They are appended to the test-automation agent's instructions on every run.

This file is managed by `factory fv lessons`, which runs the `retro` agent. Each rule is a `## L<n>: <instruction>` heading followed by a tracking marker comment, `<!-- category: <category>; subtype: <subtype>; added: <YYYY-MM-DD> -->`, then the rule text with a bad and a good example. The pipeline uses the marker to measure whether the rule reduced denials and retires or reverts rules that did not help. Changes arrive as pull requests; do not edit this file by hand.
