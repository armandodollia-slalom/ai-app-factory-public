### Design system

The existing WebApp design system is the reference when a story has no mockup (together with the story's Outputs): `src/WebApp/Components`, `src/WebAppComponents` and their `.razor.css`/`wwwroot` styles. New UI must look like it belongs.

### Styling

Existing CSS classes, variables and components are reused; no inline styles or one-off colors and fonts where the design system has them.
