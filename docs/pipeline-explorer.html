Pipeline explorer

This page shows the whole pipeline that ai-app-factory installs in a repository, from a ticket on the board to a merged pull request: change a setting on the left and the flow redraws, pick an outcome at a decision and the path through to its end is highlighted, with the board lane at each step.

It shows what the rules say will happen for one configuration (modelled in pipeline-flow.json, checked against the code by tests); it does not run the pipeline. Release 0.2.92. Overview in prose: the pipeline map.
